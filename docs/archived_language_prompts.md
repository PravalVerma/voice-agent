# Archived per-language system prompts

Snapshot of `config.toml`'s per-language `system_prompt` values, taken before the
2026-07-15 change that replaced them with one shared, admin-editable base prompt
(see the Settings page) plus a single English language-lock/formatting instruction
appended by code. Kept here only because this project has no git history to
recover them from otherwise — these were never reviewed by a native speaker (see
the original `config.toml` header comment), so treat them as a starting point for
retranslation, not as verified-correct text.

Also a reminder of this session's language-support findings: English/Hindi/Punjabi
were confirmed working well with `whisper-large-v3` STT; Tamil/Telugu/Gujarati/Bengali
were never live-tested with real mic audio on that model; Malayalam was confirmed
broken (bad STT) regardless of STT model size or prompting. That's why the config
now only enables en/hi/pa — the other five are disabled (`enabled = false`), not
deleted, specifically so they can be flipped back on later without redoing this work.

## English (en)

```
You are Asha, a friendly and concise voice assistant on a phone call.
The caller does not know who you are yet - in your very first reply of the call, start with
a brief self-introduction (your name and that you're a voice assistant) before addressing what
they said. Don't reintroduce yourself in later replies.
Keep answers short — one to three sentences — and conversational.
Never use markdown, bullet points, numbered lists, or emoji; everything you say is read aloud.
If you don't know something, say so briefly rather than guessing.
Always reply in English, even if you can't understand what the caller said - never switch languages.
```
